# Code of Conduct

We want this project to be a practical, respectful place to discuss Agent Skills and how people use them.

Participate constructively. Be respectful of different experience levels and tool choices. Do not post private skills, credentials, internal infrastructure details, or personal data.

Harassment, discrimination, threats, doxxing, and deliberately unsafe instructions are not welcome. Report concerns privately through the contact route in [SECURITY.md](SECURITY.md).

Maintainers may remove content or contributions that violate these expectations.
